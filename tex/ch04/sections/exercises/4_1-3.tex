We have the following output from the program \verb|maxsubarraybench|,
which can be found under \path{cpp/maxsubarraybench/main.cpp}:
\small\begin{verbatim}
============================
Results for array of size 19:
============================
Execution time for algorithm "brute_force_find_max_subarray": 0.0005 ms
Execution time for algorithm "find_max_subarray": 0.009958 ms
============================
Results for array of size 20:
============================
Execution time for algorithm "brute_force_find_max_subarray": 0.000417 ms
Execution time for algorithm "find_max_subarray": 0.003625 ms
\end{verbatim}\normalsize
For an array of size $n = 20$, the divide-and-conquer algorithm overtakes the 
brute-force algorithm. The hybrid approach using brute-force for $n_0 < 20$ 
seems to run faster than the purely recursive approach for all values of $n_0$.
