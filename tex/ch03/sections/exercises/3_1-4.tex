% Exercise 3.1-4
Recall that $g(n) = O(f(n))$ requires only $0 \leq g(n) \leq c \cdot f(n)$ for
all $n \geq n_0$, not equality.

Since $2^{n + 1} = 2 \cdot 2^n$, taking $c = 2$ and $n_0 = 1$ gives
$0 \leq 2^{n+1} \leq c \cdot 2^n$ for all $n \geq n_0$, so we do have
$2^{n + 1} = O(2^n)$.

However, $2^{2n} = 2^n \cdot 2^n$, so $2^{2n} \leq c \cdot 2^n$ would require
$2^n \leq c$ for all $n \geq n_0$. Since $2^n$ is unbounded, no such constant
$c \in \mathbb{R}^+$ exists, and therefore $2^{2n} \neq O(2^n)$.
