We let $T(n)$ be the worst-case running time of sorting an array of $n$
elements. For $n = 1$, we have $T(n) = \Theta(1)$, since a one-element array is
already sorted and no work is required.

If $n > 1$, the recursion sorts $A[1 \ltwodots n - 1]$ and then inserts $A[n]$
into that sorted subarray. This yields a \emph{single} subproblem of size
$n - 1$, not several, so the recursive call costs $T(n - 1)$. The insertion
itself must shift every element of $A[1 \ltwodots n-1]$ that exceeds $A[n]$ one
position to the right, which in the worst case is all $n - 1$ of them, and so
costs $\Theta(n)$. Therefore
\[
  T(n) =
  \begin{cases}
    \Theta(1) \quad &\text{if } n = 1 \\
    T(n-1) + \Theta(n) \quad &\text{otherwise} \\
  \end{cases}.
\]
Unrolling the recurrence gives
\[
  T(n) = \sum_{k = 1}^n \Theta(k) = \Theta\biggl(\frac{n(n+1)}{2}\biggr)
  = \Theta(n^2),
\]
the same worst-case running time as the iterative \textsc{Insertion-Sort}.
