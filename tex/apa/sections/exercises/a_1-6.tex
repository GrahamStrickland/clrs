\begin{proof}
  Here $n$ is a constant, independent of $i$, so the sum has a fixed number of
  terms. For each $k = 1, 2, \ldots, n$, let $g_k(i) \in O(f_k(i))$ be an
  arbitrary member of that set, so that by definition there are positive
  constants $c_k$ and $i_k$ with
  \[
    0 \leq g_k(i) \leq c_k f_k(i) \quad \text{for all } i \geq i_k.
  \]

  Put $c = \max\lbrace c_1, c_2, \ldots, c_n \rbrace$ and
  $i_0 = \max\lbrace i_1, i_2, \ldots, i_n \rbrace$, both of which exist and are
  finite precisely because there are only $n$ terms. Then for every
  $i \geq i_0$, all $n$ bounds hold simultaneously and
  \[
    0 \leq \sum_{k = 1}^n g_k(i) \leq \sum_{k = 1}^n c_k f_k(i)
    \leq c \sum_{k = 1}^n f_k(i).
  \]

  Since $\sum_{k=1}^n g_k(i)$ is an arbitrary member of $\sum_{k=1}^n
  O(f_k(i))$, and we have exhibited constants $c$ and $i_0$ witnessing that it
  lies in $O\bigl(\sum_{k=1}^n f_k(i)\bigr)$, it follows that
  \[
    \sum_{k = 1}^n O(f_k(i)) = O\biggl(\sum_{k = 1}^n f_k(i)\biggr).
  \]

  Note that the finiteness of $n$ is essential: the argument fails if $n$ is
  permitted to grow with $i$, since $\max_k c_k$ need not then be bounded.
\end{proof}
